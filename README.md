### 🚗 Selected Project Experience

**Embitel Technologies** · Jan 2021 – Present

- **TQ Systems — Side Illumination Projector (Bentley)** *(2025–present)*
  Lighting application software for welcome lamp triggered via LIN. SPI/SPI-HAL for FPGA communication, NVM handler with validation, scheduler profiling, UDS 0x22 (RDBI) for logistics data, safety module for stack-overflow and scheduler-overload monitoring.

- **Sensirion — In-Cabin CO₂ Monitoring (MIKENO)** *(2024–2025)*
  Software SPI for temperature/humidity sensor, FLASH and ADC low-level drivers, JTAG lock, batch-file binary configuration without recompile, UDS 0x22.

- **CabinAir — In-Cabin Air Purification System** *(2022–2024)*
  Built LIN stack from scratch (driver + LINIF + LINNM) with conformance compliance. Managed three OEM variants in parallel. **Achieved Embitel's first ASPICE L2 certification.**

- **Sciosense — ENS170A Air Quality Sensor (ARM Cortex-M0)** *(2022)*
  Register-file mapping for ASIC peripherals, low-level step interpreter for sensor heater control, SensorIF layer for gas-concentration computation, I2C master driver. First-time Codebeamer adoption in the company.

- **Eaton — High-Voltage Battery Management System** *(2021–2022)*
  Low-level drivers (interrupt controller, GPIO, MCU, QSPI). Integrated DMA with QSPI for full-rate sensor sampling.
